# TCCT S75C — Semantic Feasibility Milestone

存档日期：2026-08-09  
状态：已冻结的本地研究里程碑；尚未执行 S76 盲测；尚未发布到 GitHub。

## 结论

S75C 对 S75 产生的全部 1,795 个训练完美候选进行了全局语义审计。只有 2 个候选能在当前 224 个已见案例上保持 Continue/Stop 语义完全分离；先前按冻结协议选出的 S75 模型恰好是其中综合表现最好的候选，并且按验证总分与冻结协议均排名第 1。

这说明当前主要瓶颈是训练覆盖不足导致的策略可识别性问题，不是 TCCT 核心传播机制失效，也不是冻结表示发生 Continue/Stop latent token 冲突。

## 冻结模型

- 表示：PairedRadius2Radius3WithParentChildCardinality
- K：5
- 参数：`{-1,0,-1,-1,-1,0,1,-1}`
- 训练所得策略：`{{3,1},{3,3},{4,3}}`
- 训练策略在当前全部已见案例上：192/224
- 全局安全策略：`{{1,3},{2,2},{3,1},{3,2},{3,3},{4,3}}`
- 全局安全策略在当前全部已见案例上：224/224
- 待补 Continue token：`{{1,3},{2,2},{3,2}}`
- Stop 误触发：0

全局安全策略使用了验证标签，只能作为 S75D 的“验证后策略补齐”使用，不能表述为训练自动学习所得。此存档没有把该策略应用到冻结模型，也没有运行 S76。

## 效率边界

当前实验使用 8 个三值离散参数，共 6,561 个参数组合；S75C 对 1,795 个训练完美候选逐一审计 224 个案例。这个规模在普通 CPU 上即可穷举，不需要 GPU，说明当前窄域合成任务中的搜索效率和样本效率都很好。

但这不是大规模神经网络训练，而是小型离散表示族上的精确搜索与规则策略选择。尚未记录严格的端到端耗时、内存和随图规模增长的复杂度，因此不能据此宣称现实任务或大规模图上的效率也很高。
