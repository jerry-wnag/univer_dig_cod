# TCCT S125-E：饱和低阶神经基线五世界测试

## 结论

这次测试修正了 S125-C 中神经基线低阶验证准确率只有 70% 多的问题。新的序列神经基线在五个确认世界中都先达到预声明的低阶饱和门槛，保存并重新加载冻结模型后，才打开高阶测试。

强化基线后，神经网络的高阶成绩显著提高，但仍未追平 TCCT：

- TCCT 高阶状态整签名精确率：`370/370 = 100%`
- 神经基线高阶状态整签名精确率：`194/370 = 52.43%`
- TCCT 高阶转移整签名精确率：`2960/2960 = 100%`
- 神经基线高阶转移整签名精确率：`954/2960 = 32.23%`

因此，原先弱训练的 neural baseline 确实低估了神经网络；但 TCCT 在“整个 14-bit 结构签名必须完全正确”的未见高阶组合与转移上仍保持明显优势。

## 预声明低阶饱和门槛

- 低阶训练 balanced accuracy 不低于 `0.99`
- 不重叠的低阶验证路径 balanced accuracy 不低于 `0.98`
- 验证集完整 14-bit 签名 exact accuracy 不低于 `0.85`
- 任一世界没有通过门槛，则不打开该世界高阶测试，也不能记作 TCCT 获胜

每个世界只使用 46 个 interaction order 不超过 2 的低阶状态：每状态 128 条训练路径、32 条不重叠验证路径，即 5,888 条训练序列和 1,472 条验证序列。训练、选择模型和选择随机种子均未使用高阶标签。

## 神经基线与参数规模

本次基线是一个处理动作历史的 GRU 多标签序列 reasoner：

- 动作嵌入：64
- GRU hidden size：128
- GRU 层数：2
- 输出：14-bit 结构签名
- 可训练参数：176,270
- 每个世界训练 3 个预声明随机种子，仅按低阶验证指标选取一个模型

对应的 TCCT 冻结结构只有 41 或 42 个 conditional transition cells。若只按数量相除，神经基线约为 TCCT cells 的 4,200–4,300 倍；但 symbolic cell 与神经权重并非完全同一种参数，不能把这个倍率当成严格的存储或计算倍率。可以可靠得出的结论是：在本任务中，TCCT 用远小得多、可解释的稀疏结构获得了更高的严格高阶 exact accuracy。

## 完整性与证据边界

- 五个世界从 20 个已冻结严格世界中按固定随机种子 `1259001` 预先抽取：`1257019, 1257018, 1257007, 1257010, 1257015`。
- 源码 SHA-256 在高阶测试前锁定，并与预注册清单一致。
- 五个神经模型的文件哈希均与结果记录一致。
- 每个世界均满足“模型文件保存 -> freeze metadata 写入 -> 高阶结果写入”的顺序。
- 原严格世界记录均确认：TCCT freeze 前未触碰高阶数据，TCCT 状态和转移 exact 均为 1.0，strict protocol pass。
- TCCT 核心的重写、冻结、去重和原迭代规则没有被修改。

本轮属于“从既有严格 fresh-world 池中随机抽取冻结世界的离线确认性压力测试”，不是重新调用 Wolfram 生成的五个全新 fresh worlds。原因是当前 Wolfram CLI 许可证不可用。它足以公平回答“把神经低阶训练推到接近饱和后，原优势是否还存在”，但证据等级应低于一次从零生成并封存的全新 prospective 五世界复现。
