# S132-K4B Out-of-Family Concept Transfer

This stage reuses the frozen K3B learner and K4A concept mechanism without
modification. It starts with an empty library and tests twelve fresh worlds from
four new generator families, twelve action-image-rank-matched random controls,
four near-law challenges, and independent state-relabeling invariance.

The concept language remains fixed to exact anonymous action-word shortening
relations of maximum length four. No K4A library is preloaded. Generator truth
is sealed, the canonical TCCT core is unchanged, observation noise is not mixed
into this stage, and no PDF is produced.

The purpose is to test whether K4A's bounded concepts survive generator-family
shift. It does not test open-ended primitive or language invention.

The frozen formal run passed and was independently reconstructed. See
`RESULTS.md` for the complete results, adverse cases, runtime, and claim limits.
